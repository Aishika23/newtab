I have used newsdata.io and apod api to make the website interactive. 
I used apod to change the background image everyday, if there is a youtube url a custom image selected by me gets displayed.
I made a seperate news column to display recent news from newsdata.io.
To make the search tab i used Google's link of google.com/search and then concatenated the input box's value to it to get a search tab.
I used a little bit of ai (chatgpt) to help me with api since i am very new to it.
I have also made different css for mobile and computer
